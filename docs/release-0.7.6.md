# ParaNAM Trainer 0.7.6

- Plan supports live drag-and-drop previews and highlights controls and the add button on hover.
- Selecting a control no longer recalculates capture recommendations. Capture grid limits account for both marked Gain/Drive controls.
- Queue and Capture reuse table cells, and Compare preserves the model selector when its contents are unchanged.
- Scrolling over closed dropdowns and value fields no longer changes their values.
- A dimmed overlay with an animated spinner blocks input while longer foreground calculations are running, including plan generation, capture ordering, and model discovery.
